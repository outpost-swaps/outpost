Outpost (Linux, 64-bit x86)
==========================

Start it:
    ./bin/Outpost

Add it to your application menu with the Outpost icon (optional, for your user only):
    ./install-menu-entry.sh

The menu entry points at this folder, so keep the folder where it is, or run the script again
after you move it.

Needs a recent 64-bit x86 Linux (glibc 2.35 or newer: Ubuntu 22.04, Debian 12, Fedora 36 and later),
with a desktop that has the usual GTK 3 libraries.

If you would rather install a package, use the .deb (Debian, Ubuntu, Mint) or the .rpm (Fedora,
openSUSE) from the same release page: they add the menu entry for you.

Before you run anything you downloaded, check its signature and checksum (see the release page).
Outpost is beta software and has not been independently audited: use small amounts.
